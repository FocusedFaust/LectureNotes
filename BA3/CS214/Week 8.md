### Duration API

⇒ Comes from the `scala.concurrent.duration.Duration` package.
⇒ The syntax to define a duration object is `Duration(length, unit)`. Extractors, parsing and arithmetic are also included in the definition of durations.
⇒ This class includes various methods on two durations.
